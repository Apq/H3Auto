# 打铁助手

手动战斗自动化插件（名称：打铁助手）。

## 战斗中人工接管

全部部队都配置了自动动作后，可用热键临时拿回控制权（不改 5 套方案）：

- `F9`：启动 / 停止打铁（本场自动与全手动之间切换）；每场战斗进场默认全手动，按 `F9` 才开始自动
- `J`：锁定当前或下一支部队，人工行动一次后恢复到按 `J` 前的模式

热键可在 `H3Auto.default.ini` 的 `[Hotkeys]` 修改。

设置面板右上角 `?` 可查看完整使用说明。

## 力盾战法

在「保持状态」页第一行设置「力盾落点」，点√确认；仍由 F9 启动。

- 沿用循环移动的设置方式：点「＋」新增、点已有坐标重选、右键删除；最多两个落点，坐标显示为 A01 样式。点选时右键或 ESC 取消，不绘制蓝底，不透传部队动作。
- 有落点即保持该处力盾，删光即不补盾。没有独立页、启用开关或手动首盾捕获。
- 盾在不补，消失后按落点顺序优先补施。优先级：力盾 > 保活 > 其它保持状态 > 召唤；不做固定回合计时，状态页的剩余回合阈值不作用于力盾。
- 原版英雄每回合只能施法一次：两个点都缺盾时先补第一点，第二点下一回合再补；已施法的回合继续部队动作，不强行连续补两盾。
- 按当前测试要求不做拥有法术、魔法书、魔力、宝物/地形或落点合法性预检，也不核验施后生成结果；直接调用原版施法，返回后本回合不再重复尝试。原版拒绝或无效果返回时仍继续动作，不承诺此测试版始终有盾保护。
- 落点随五套方案存档，同场重打重新扫描盾，不保留障碍指针。
- 仅用于敌方双格地面近战、我方占角落三格且每回合我方先行动的场景。飞行、远程、传送、速度变化及到期时序仍需游戏验证；插件不会自动布阵。
- 原有自动停止设置仍有效。战斗 JSON 存档格式为 v4，旧格式视为无存档，不迁移。

## 保活与自动召唤

保活、保持状态和召唤是同一条施法通道。玩家方没有英雄时整条不走。
有英雄时保活优先，没人该救再补状态，仍不施法且召唤已启用才召唤：

- 保活按队设置：每支部队在卡片底部「保活:」下拉选自己的方式（默认不保活）——
  剩余数量≤（配「剩≤」阈值，默认 2）或 损失量>恢复量；多队该救时救血量最低的一队。
  亡灵自动用聚灵、活体用复活。
- 「保持状态」页用「+」加入已学会的全体魔法，最多 8 项；说明行下方
  「剩余回合≤N 时补」阈值（1..9，默认 1，随方案保存）。
  这些法术全都保持：哪一项在任何一支部队上先降到阈值（含还没上过的）
  就补哪一项，多个同时到期补剩余最少的那项；等级不够或免疫的部队
  不参与判断。
  敌方减速（标「敌方」，只有专家级才出现）单独算：只要敌方还有
  任意一队的减速效果剩余回合超过阈值就不再重复施放（敌方可能抵抗，
  没全中也算完成任务），等所有能接受减速的敌队效果都降到阈值以内
  才再施。这些法术都是全体施放。
- 每次行动（还有施法次数时）先补所配置落点的缺失力盾，再判保活；没人该救再补其它状态；
  仍不施法且召唤已启用才判召唤。一回合只施一次法，而且这条限制
  是游戏自己的：插件自动施过后，本回合玩家手动施法也会被判定为
  已施过；反过来玩家先手动施过，插件本回合也不再自动施。
- 「召唤」页第一行「启用自动召唤」勾选框控制开关（与「停止:」同行，
  默认不勾＝不召唤）：
  - 魔法：自动（已学四系中召唤总量最大，首次成功后本场锁定）或固定一系；
  - 时机：存活本体部队 + 存活召唤物（不含战争机器、克隆）< 队数阈值（默认 2）、
    剩余血量合计 ≤ 血量阈值（默认 750），两条件按「和 / 或」下拉组合
    （默认「和」＝都满足才施放，「或」＝任一满足即施放）；
  - 召唤物共用行动（默认防御）：手动 / 防御 / 散开（≥2 格 → ≥1 格 → 防御分级降级）/
    随机移动（可勾选降级为防御）。
- 自动停止第二条件：「敌方魔力≤[阈值] 时停」默认勾选，敌方英雄（有魔法书）
  魔力 ≤ 阈值（默认 6，0..32767 可调、随方案存档）时与停止回合数任一满足即切回手动。

召唤物上场即自动接管执行；战斗结束/重打清空锁定。详见 `使用说明.txt`。

```powershell
cmd /c build.bat /t:Rebuild
```

## 单元测试

纯策略核心位于 `modules/PolicyCore.hpp`，生产插件和 `tests/PolicyCoreTests.cpp` 共用，不依赖游戏进程。

```powershell
$env:H3AUTO_BUILD_TESTS = '1'
cmd /c build.bat /t:Rebuild
Remove-Item Env:H3AUTO_BUILD_TESTS
.\Release\tests\PolicyCoreTests.exe
```

覆盖：战争机器技能分支、面板准入、远程/急救独立选择器、候选评分、非法行动规范化、旧施法槽兼容、结果窗接受/取消生命周期、稳定部队身份重排、召唤时机判定、状态保持补法判定（含敌方减速语义与补状态阈值）、战斗指纹、存档去重。新增双力盾落点归一化、缺盾选择矩阵及五方案逐槽存档去重。

## 部队身份与快速战斗重打

插件不使用 `_BattleStack_` 指针或战场数组下标作为跨重打身份。配置身份与本轮运行定位分开：

- 普通开战部队：使用 `side + source_army_slot`；数量、位置、伤亡和战斗效果变化不会改变身份。
- 战争机器：使用战争机器类型和同类序号；战争机器通常没有有效的 `source_army_slot`。
- 召唤物和克隆物：没有跨重打配置身份，不继承原部队规则。
- `army_slot_ix`、指针和行动队列：只用于当前战斗中的定位和执行，不作为持久配置键。

HD 快速战斗点“取消/重打”后，5 套方案保留；插件按稳定身份把方案重排到新战场槽位，清除旧指针、等待状态和循环游标，再重新绑定当前战场。点击“确定/接受”才清空方案。
