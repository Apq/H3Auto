# 打铁助手（H3Auto）

《英雄无敌 III》SoD / HD Mod 手动战斗自动化插件：按玩家配置重复部队行动与英雄施法，不接管敌方或原版自动战斗。

## 使用入口

- [使用说明](<使用说明.txt>)：安装、行动、施法、力盾、保活、状态、召唤和方案操作。
- 默认 `F9` 启停，`J` 临时接管一次后返回原模式，`P` 或右键“自动战斗”打开设置；热键可配置。
- 进场及重打默认全手动；打开面板和勾号停止自动，之后需按 F9 启动。
- 五方案独立编辑，勾号提交全部草稿，取消不提交；同场重打保留，接受结果清空进程方案。
- 勾号按指纹自动保存配置，首次开面板可载历史草稿，仍需确认生效。只保存方案，不恢复战场损血、站位或随机序列。
- 部队循环快捷施法已删除，卡片缩为511×88；“攻击魔法”页配置方案级智能攻击，最多8条（一行两条），控件按法术类别出现：单体只选目标（远程飞兵速度优先/随机）、范围点落点按钮到战场选唯一落点、全体无选项。
- 力盾 > 保活 > 其它状态 > 召唤共用通道；自动停止检查后才尝试智能攻击。力盾无预检直接施法的测试规则与风险见[英雄施法](<docs/03-英雄施法与自动停止.md>)。

与战场存档同时启用时的自动命令互让与读档复位，见[协作与防冲突](<docs/12-战场存档协作与防冲突.md>)。单独启用不依赖另一插件。

## 构建与部署

HD Mod / patcher_x86、仓库 H3API、Visual Studio 18 / v145；Win32 / x86 Release。BAT 入口：

```powershell
cmd /c build.bat /t:Rebuild
cmd /c deploy.bat
# 或一步：cmd /c build_and_deploy.bat
```

产物 [H3Auto.dll](<Release/H3Auto.dll>)。测试分支、当前部署目标、保留规则和核对方法见[构建部署与测试](<docs/10-构建部署与测试.md>)。更新后完全退出并重启游戏。

## 验证边界

生产库只读写 JSON v5，v4及更早不兼容、不迁移；旧rules.spells明确拒绝，未用H3AP纯文本接口已删除。构建/纯策略不能替代真实输入、施法、重打和字体显示验收，遗留集中于[验证待办](<docs/11-验证边界与待办.md>)。

智能攻击的资格是“已学或穿戴装备赋予”（HasSpell：泰坦之箭等穿上即列出、脱下即消失；装备/卷轴放背包不算）。白名单：单体 15/16/17/18/19/57、范围 20/21/22/23、全体 24/25/26，火墙暂不纳入。一行两条并排配置，控件按类别出现：单体只显目标下拉（远程飞兵速度优先/随机）、范围只显落点按钮（点它到战场选唯一落点，左键重选/右键删除）、全体两者皆无。游戏实测仍待执行。范围/连锁保留原版友伤、免疫和抗性语义，详见[智能攻击规则](<docs/03-英雄施法与自动停止.md#attack-magic>)及[接口考证](<../H3Note/H3Auto智能攻击施法接口考证.md>)。
