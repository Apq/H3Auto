## 历史资料

[历史导航](<历史/README.md>)单独保存旧方案、实施过程和阶段性记录，不是当前行为或测试通过凭据。H3AP、四轮关联、ZIP、全局保活方案都有归档说明；当前生产配置库为 JSON v4。

## 阅读与维护

- 玩家从使用说明开始；开发先读架构再进功能分册；排障先看诊断和验证边界。
- 原数字章节号保留，§ 引用已链接所属分册；今后更新对应功能正文，不再追加完整设计副本。
- 已实现、离线通过、实机验收分别标明。临时验证产物不被重写为新的通过声明。
- 功能更新同步必要的玩家说明与语言配置；历史只补勘误/裁定，不回改早期需求伪造一致性。
- 文档 UTF-8 无 BOM / CRLF，相对链接以所在目录为基准。
