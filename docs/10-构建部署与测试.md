## 14. 构建与部署

- **统一入口**：编译用 [build.bat](<../build.bat>)，部署用 [deploy.bat](<../deploy.bat>)，一步编译部署用 [build_and_deploy.bat](<../build_and_deploy.bat>)；三者均是有效入口。底层 PS1 由 BAT 调用，不单独运行，也不直接调用 MSBuild。
- [deploy.ps1](<../deploy.ps1>) 强制覆盖：`H3Auto.dll`、[H3Auto.default.ini](<../H3Auto.default.ini>)、[使用说明.txt](<../使用说明.txt>)、`lang\*.ini`、`img\*.*`；并删除旧包名 `战场自动化\H3Auto.dll`（防双加载）。`H3Auto.user.ini` 与战斗存档 `*.json` 不覆盖。
- 源文件 UTF-8，中文游戏字体走 GBK；换行 CRLF。

- DLL 在游戏进程启动时加载，改动后必须**完全重启游戏**才生效。

## 全量编译

依赖 HD Mod / patcher_x86 与本仓库 H3API。Visual Studio 18 / v145、Release|Win32、C++20、结构 1 字节对齐（/Zp1）。以[工程配置](<../H3Auto.vcxproj>)为准。

在项目目录运行：

```powershell
cmd /c build.bat /t:Rebuild
```

输出 [H3Auto.dll](<../Release/H3Auto.dll>)。检查退出码、错误/警告统计与产物时间戳；增量成功不替代全量验证。

## 独立策略与几何测试

[PolicyCore.hpp](<../modules/PolicyCore.hpp>) 由生产和 [PolicyCoreTests.cpp](<../tests/PolicyCoreTests.cpp>) 共用，不依赖游戏进程。文字矩形几何核心见 [TextLayoutCore.hpp](<../modules/TextLayoutCore.hpp>)。

```powershell
$env:H3AUTO_BUILD_TESTS = '1'
try {
    cmd /c build.bat /t:Rebuild
    if ($LASTEXITCODE -ne 0) { throw '测试构建失败' }
    .\Release\tests\PolicyCoreTests.exe
    if ($LASTEXITCODE -ne 0) { throw '测试运行失败' }
} finally {
    Remove-Item Env:H3AUTO_BUILD_TESTS -ErrorAction SilentlyContinue
}
```

测试分支只编译测试工程，不重建生产 DLL。覆盖战争机器技能、行动和目标集、评分、规范化、结果窗生命周期、稳定身份重排、召唤、状态保持及减速语义、指纹、去重、力盾和文字矩形。数量以实际输出为准，不沿用历史旧计数。

## 部署与资源

```powershell
cmd /c deploy.bat
```

当前本机目标来自 [deploy.ps1](<../deploy.ps1>)，不是通用安装硬编码：

```text
D:\Heroes3\Heroes3_2026.10.07\_HD3_Data\Packs\热血插件\
```

部署覆盖 DLL、默认配置、使用说明、语言和图片；保留 user 配置及方案 JSON，移除旧“战场自动化”包同名 DLL 防双加载。修改目标先核对脚本实际值。卡片/金框尺寸改变需重生 PCX；字体适配见[输入绘制](<06-设置面板与输入绘制.md>)。游戏完全退出再启动才加载更新 DLL。
