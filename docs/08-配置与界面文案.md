## 16. 界面文案 i18n 与日志分级

<a id="section-16-1"></a>
### 16.1 文案外置（modules/UiTexts.inc.cpp）

- 全部界面文本（面板/帮助模态/表格控件/下拉选项/tips/状态栏/战场 HUD 角标）经 `T("节.键")` 取文案；动态数字用格式串（如 `panel.profile_btn_fmt = 方案 %d`）。
- 加载链：`H3Auto.default.ini [General] Language`（缺省 zh-CN，`H3Auto.user.ini` 可覆盖）→ DLL 同目录 `lang\<语言>.ini` 覆盖命中键；缺文件/缺键/语言名非法回落代码内置默认表（`kUiTextDefaults`，与 [zh-CN.ini](<../lang/zh-CN.ini>) 镜像，改文案两处同步）。
- ini 统一 UTF-8 带 BOM，读写走手写解析 `IniReadUtf8`/`IniWriteKeyUtf8`（modules/IniUtf8.inc.cpp；`GetPrivateProfileStringA` 是 ANSI 接口，读 UTF-8 中文必乱码，已全部替换）。行内注释只认 `;`（`#` 只在行首，保护 `{#RRGGBB}`）。
- **失控防护**（`IniReadFileToBuffer_` / `IniWriteKeyUtf8`）：读上限 `kIniReadCap_`=64KB，超限当文件不存在（旧版曾对 224MB 的 user.ini 整体读入，32 位进程 `bad_alloc` 直接崩游戏）；写入侧超 `kIniRebuildThreshold_`=64KB 的文件整体重建而非追加；行分裂按终止符判断 `\r\n`（写 0 后不能再回读 `p[-1]`，否则 CRLF 的 `\n` 被漏掉、重写时行被拆成空行堆积）。
- 值支持富文本颜色标记与 %s/%d；仅状态栏键（`panel.status_*`、`help.pack_*`、`help.log_level_set`、`tips.color_wrap`）走富文本绘制，其他位置带标记会原样显示。
- 行动/目标选择器标签沿用序号键（`[actions] 0..`、`[selectors] 0..`，与 `AA_COUNT`/`SEL_COUNT` 对齐，含召唤物散开/随机移动动作），由 LoadUiTexts 填 `g_action_labels/g_selector_labels`。[zh-CN.ini](<../lang/zh-CN.ini>) 共 143 键、7 节（panel/help/tips/cell/hud/actions/selectors）。
- 原 H3Auto.ini 的 `[Panel]/[Actions]/[Selectors]` 已迁入 lang 文件。
